# Release artifacts

This directory is the default location for opt-in archived release evidence that is generated outside the deterministic public-network-free release run.

- `live_proxycommand_report.txt`: generated by `test_live_proxycommand_transport` when `SSH_LIB_LIVE_PROXYCOMMAND_REPORT=release_artifacts/live_proxycommand_report.txt` is set. `check_live_proxycommand_report` uses this path by default when `SSH_LIB_REQUIRE_LIVE_PROXYCOMMAND_REPORT=1` is enabled and no explicit report path is provided.

Archived reports must not contain secrets or raw ProxyCommand strings. They contain deterministic key-value scenario metadata, strict host-key settings, ProxyCommand lifecycle diagnostics, and final `result=PASS` evidence.
- `live_git_matrix_report.txt`: default path for `check_live_git_matrix_report` when `SSH_LIB_REQUIRE_LIVE_GIT_REPORT=1` is enabled and `SSH_LIB_LIVE_GIT_REPORT` is unset.
- `sftp_v4_v6_interop_report.txt`: default path for `run_sftp_v4_v6_interop` and `check_sftp_v4_v6_interop_report` when no SFTP v4 report override is set.
- `sftp_fuzzer_seed_report.txt`: default path for `run_sftp_fuzzer_seed_corpus` when `SSH_LIB_SFTP_FUZZ_REPORT` is unset.
